## What are Callable Classes?

A callable class is a class that can be **invoked like a function** by implementing the `call()` method.

---
## Basic Example

```dart
class Multiplier {
  final int factor;

  Multiplier(this.factor);

  int call(int value) => value * factor; // makes instance callable
}

void main() {
  var triple = Multiplier(3);
  print(triple(5));  // 15 — called like a function
  print(triple(10)); // 30
}
```

---
## Why Use Callable Classes?

They let you create **stateful function-like objects** — closures with named structure and multiple fields.

```dart
class Validator {
  final int minLength;
  final int maxLength;
  final RegExp pattern;

  Validator({
    required this.minLength,
    required this.maxLength,
    required this.pattern,
  });

  bool call(String input) {
    if (input.length < minLength || input.length > maxLength) return false;
    return pattern.hasMatch(input);
  }
}

void main() {
  final emailValidator = Validator(
    minLength: 5,
    maxLength: 100,
    pattern: RegExp(r'^[\w.-]+@[\w.-]+\.\w+$'),
  );

  print(emailValidator('user@example.com')); // true
  print(emailValidator('bad'));              // false
}
```

## Callable Class as a Function Type

A callable class instance can be passed where a function is expected.

```dart
class Adder {
  final int amount;
  Adder(this.amount);
  int call(int x) => x + amount;
}

void main() {
  List<int> nums = [1, 2, 3, 4, 5];
  var addTen = Adder(10);

  var result = nums.map(addTen).toList(); // passed as function
  print(result); // [11, 12, 13, 14, 15]
}
```

## Callable Class vs Closure

| Feature | Callable Class | Closure |
|---|---|---|
| Has named type | ✅ | ❌ Anonymous function |
| Can store state/fields | ✅ | ✅ (captures outer variables) |
| Supports multiple methods | ✅ | ❌ |
| Testable / mockable | ✅ Easier | ❌ Harder |
| Syntax | `instance(args)` | `fn(args)` |
| Reusable as object | ✅ | Limited |
| Typical use | Complex reusable behavior | Small callbacks and inline logic |

---
## Notes

- The `call()` method can have any signature — parameters, return type, named args
- Dart does not have a formal `Callable` interface — it's a convention
- Used heavily in Flutter for widget builders and callbacks
