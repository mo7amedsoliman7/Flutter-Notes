## Basic Enums

```dart
enum Direction { north, south, east, west }

void main() {
  Direction dir = Direction.north;
  print(dir);       // Direction.north
  print(dir.name);  // north
  print(dir.index); // 0
}
```

## Enhanced Enums (Dart 2.17+)

Enums can now have **fields, constructors, methods, and implement interfaces** — just like classes.

```dart
enum Planet {
  mercury(3.303e+23, 2.4397e6),
  venus(4.869e+24, 6.0518e6),
  earth(5.976e+24, 6.37814e6),
  mars(6.421e+23, 3.3972e6);

  final double mass;       // in kilograms
  final double radius;     // in meters

  const Planet(this.mass, this.radius);

  static const double G = 6.67430e-11;

  double get surfaceGravity => G * mass / (radius * radius);

  double surfaceWeight(double otherMass) => otherMass * surfaceGravity;
}

void main() {
  const earthWeight = 75.0;
  const mass = earthWeight / Planet.earth.surfaceGravity;

  for (var p in Planet.values) {
    print('${p.name}: ${p.surfaceWeight(mass).toStringAsFixed(2)} N');
  }
}
```

## Enums Implementing Interfaces

```dart
abstract class Describable {
  String describe();
}

enum Status implements Describable {
  pending('Waiting for review'),
  approved('Ready to proceed'),
  rejected('Needs revision');

  final String label;
  const Status(this.label);

  @override
  String describe() => 'Status: $label';
}

void main() {
  print(Status.approved.describe()); // Status: Ready to proceed
}
```

## Enums with Getters and Methods

```dart
enum HttpMethod {
  get, post, put, patch, delete;

  bool get hasBody => this == post || this == put || this == patch;
  bool get isIdempotent => this != post;

  String toUpperCase() => name.toUpperCase();
}

void main() {
  print(HttpMethod.post.hasBody);      // true
  print(HttpMethod.get.isIdempotent);  // true
  print(HttpMethod.delete.toUpperCase()); // DELETE
}
```

## Switch on Enums (Exhaustive)

```dart
enum TrafficLight { red, yellow, green }

String action(TrafficLight light) => switch (light) {
  TrafficLight.red    => 'Stop',
  TrafficLight.yellow => 'Slow down',
  TrafficLight.green  => 'Go',
};
```

The compiler warns if a case is missing — no `default` needed.

## Enum Utility Members

Every enum gets these for free:

```dart
// All values as a list
print(Direction.values); // [Direction.north, ...]

// By name
print(Direction.values.byName('north')); // Direction.north

// Name string
print(Direction.north.name); // north

// Index
print(Direction.north.index); // 0
```

## Enhanced Enum Rules

- Constructor must be `const`
- Cannot extend other classes (enums implicitly extend `Enum`)
- Can implement interfaces
- Can have static fields and methods
- Cannot be instantiated outside the enum declaration
