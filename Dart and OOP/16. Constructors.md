## Default Constructor

If no constructor is defined, Dart provides a no-argument default.

```dart
class Dog {
  String name = 'Unknown';
}

var d = Dog(); // uses default constructor
```

---
## Generative Constructor

The standard constructor. Use shorthand `this.field` to assign directly.

```dart
class Dog {
  String name;
  int age;

  Dog(this.name, this.age); // shorthand initializer
}
```

---
## Named Constructor

Dart allows multiple constructors via names.

```dart
class Point {
  double x, y;

  Point(this.x, this.y);

  Point.origin()
      : x = 0,
        y = 0;

  Point.fromMap(Map<String, double> map)
      : x = map['x']!,
        y = map['y']!;
}

var p1 = Point(3, 4);
var p2 = Point.origin();
```

---
## Initializer List

Runs before the constructor body. Used for `final` fields and assertions.

```dart
class Rectangle {
  final double area;

  Rectangle(double width, double height)
      : area = width * height;
}
```

---
## Redirecting Constructor

Delegates to another constructor in the same class.

```dart
class Color {
  int r, g, b;

  Color(this.r, this.g, this.b);

  Color.red() : this(255, 0, 0);
  Color.black() : this(0, 0, 0);
}
```

---
## Constant Constructor

Creates compile-time constants. All fields must be `final`.

```dart
class ImmutablePoint {
  final double x, y;
  const ImmutablePoint(this.x, this.y);
}

const p = ImmutablePoint(1, 2); // compile-time constant
```

---
## Constructor Types Summary

| Type        | Use Case                        |
| ----------- | ------------------------------- |
| Generative  | Standard object creation        |
| Named       | Multiple creation paths         |
| Redirecting | Delegate to another constructor |
| Constant    | Compile-time immutable objects  |
| Factory     | Custom logic / caching          |
