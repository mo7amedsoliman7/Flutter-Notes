## Interfaces in Dart

Dart has **no `interface` keyword**. Every class implicitly defines an interface. Use `implements` to fulfill that contract.

---
## `implements` Keyword

When a class implements another, it must **provide its own implementation** for every member.

```dart
class Printable {
  void printInfo() {}
}

class Dog implements Printable {
  String name;
  Dog(this.name);

  @override
  void printInfo() => print('Dog: $name');
}
```

---
## Implementing Multiple Interfaces

Unlike `extends`, a class can `implement` many types.

```dart
abstract class Flyable {
  void fly();
}

abstract class Swimmable {
  void swim();
}

class Duck implements Flyable, Swimmable {
  @override
  void fly() => print('Duck flying');

  @override
  void swim() => print('Duck swimming');
}
```

---
## `implements` vs `extends`

| Feature | `extends` | `implements` |
|---|---|---|
| Inherits implementation | ✅ | ❌ (must re-implement all members) |
| Inherits state/fields | ✅ | ❌ |
| Limit | One class only | Multiple interfaces/classes |
| Use for | Reusing behavior | Enforcing a contract |
| Method overriding | Optional | Required |
| Relationship | “is-a” inheritance | Capability / API agreement |

## Abstract Class as Interface

Using an abstract class as an interface is the idiomatic Dart pattern.

```dart
abstract class Logger {
  void log(String message);
  void error(String message);
}

class ConsoleLogger implements Logger {
  @override
  void log(String message) => print('[LOG] $message');

  @override
  void error(String message) => print('[ERROR] $message');
}

class FileLogger implements Logger {
  @override
  void log(String message) { /* write to file */ }

  @override
  void error(String message) { /* write to file */ }
}
```

## `interface` Class Modifier (Dart 3+)

Dart 3 introduced explicit class modifiers to control how a class can be used.

```dart
interface class Shape {
  double area() => 0;
}

// Can implement but not extend outside this library
class Circle implements Shape {
  double radius;
  Circle(this.radius);
  @override
  double area() => 3.14159 * radius * radius;
}
```
