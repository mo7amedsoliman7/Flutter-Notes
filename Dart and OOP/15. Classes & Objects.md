# What is a Class?

A **class** is a blueprint for creating objects. It defines properties (fields) and behaviors (methods).

```dart
class Car {
  String brand;
  int year;

  Car(this.brand, this.year);

  void describe() {
    print('$brand ($year)');
  }
}
```

---
## What is an Object?

An **object** is an instance of a class — a concrete entity created from the blueprint.

```dart
void main() {
  Car myCar = Car('Toyota', 2022);
  myCar.describe(); // Toyota (2022)
}
```

---
## Key Concepts

|Concept|Description|
|---|---|
|**Field**|A variable that holds the state of an object|
|**Method**|A function that defines the behavior of an object|
|**Instance**|A concrete object created from a class|
|`this`|Refers to the current instance|

---
## `this` Keyword

```dart
class Person {
  String name;

  Person(String name) {
    this.name = name; // disambiguates field from parameter
  }
}
```

---
## Notes

- In Dart, everything is an object (even `int`, `bool`)
- Classes are reference types — variables hold a reference, not a copy
- Use `final` fields for immutable properties
