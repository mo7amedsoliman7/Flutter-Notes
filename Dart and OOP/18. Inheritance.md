## What is Inheritance?

Inheritance allows a class to **reuse and extend** the behavior of another class.

```
Animal
  └── Dog
  └── Cat
```

---
## `extends` Keyword

```dart
class Animal {
  String name;

  Animal(this.name);

  void speak() => print('...');
}

class Dog extends Animal {
  Dog(String name) : super(name);

  @override
  void speak() => print('Woof!');
}
```

---
## `super` Keyword

Used to call the parent class constructor or methods.

```dart
class Vehicle {
  int speed;
  Vehicle(this.speed);
}

class Car extends Vehicle {
  String brand;

  Car(this.brand, int speed) : super(speed); // calls Vehicle constructor
}
```

---
## `@override`

Annotate overridden methods to make intent explicit and catch mistakes.

```dart
class Shape {
  double area() => 0;
}

class Circle extends Shape {
  double radius;
  Circle(this.radius);

  @override
  double area() => 3.14159 * radius * radius;
}
```

---
## Single Inheritance

Dart supports **single inheritance** only — a class can extend only one parent.

```dart
class A {}
class B extends A {}
// class C extends A, B {} // ❌ not allowed
```

For multiple inheritance behavior, use [[08_Mixins]].

---
## Inheritance Chain

```dart
class Animal { ... }
class Mammal extends Animal { ... }
class Dog extends Mammal { ... } // inherits from both
```

---
## Key Rules

|Rule|Detail|
|---|---|
|One parent only|Use mixins for multiple inheritance|
|`super()` in constructor|Must be last in initializer list|
|`@override`|Optional but strongly recommended|
|`final` class|Cannot be extended (use `base` or `sealed` for constraints)|
