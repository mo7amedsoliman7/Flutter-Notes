## What are Getters & Setters?

Getters and setters are special methods that provide **controlled access** to an object's properties. They look like field accesses but run code underneath.

---
## Basic Getter

```dart
class Circle {
  double radius;

  Circle(this.radius);

  double get area => 3.14159 * radius * radius; // computed property
  double get circumference => 2 * 3.14159 * radius;
}

void main() {
  var c = Circle(5);
  print(c.area);          // 78.53...
  print(c.circumference); // 31.41...
}
```

---
## Basic Setter

```dart
class Temperature {
  double _celsius = 0;

  double get celsius => _celsius;

  set celsius(double value) {
    if (value < -273.15) throw ArgumentError('Below absolute zero!');
    _celsius = value;
  }
}

void main() {
  var t = Temperature();
  t.celsius = 100;
  print(t.celsius); // 100.0
  // t.celsius = -300; // throws ArgumentError
}
```

---
## Getter + Setter Pair

```dart
class Rectangle {
  double _width;
  double _height;

  Rectangle(this._width, this._height);

  double get width => _width;
  set width(double value) {
    if (value <= 0) throw ArgumentError('Width must be positive');
    _width = value;
  }

  double get height => _height;
  set height(double value) {
    if (value <= 0) throw ArgumentError('Height must be positive');
    _height = value;
  }

  double get area => _width * _height;
}
```

---
## Read-Only Property

Provide only a getter (no setter) to make a property read-only.

```dart
class Person {
  final String firstName;
  final String lastName;

  Person(this.firstName, this.lastName);

  String get fullName => '$firstName $lastName'; // read-only computed
}
```

## Getters vs Methods

| Feature | Getter | Method |
|---|---|---|
| Syntax at call site | `obj.name` | `obj.name()` |
| Takes parameters | ❌ | ✅ |
| Convention | Computed/read-only property | Action or behavior |
| Looks like a field | ✅ | ❌ |
| Can contain logic | ✅ | ✅ |
| Typical use | Derived values, formatting | Operations, processing, mutations |

```dart
// Prefer getter for derived properties
double get area => width * height; // ✅

// Prefer method when it takes parameters
double scale(double factor) => area * factor; // ✅
```
