## What is Polymorphism?

Polymorphism means **many forms** — the ability to treat objects of different types through a common interface.

---
## Runtime Polymorphism (Method Overriding)

The correct method is chosen at runtime based on the actual object type.

```dart
class Shape {
  double area() => 0;
}

class Circle extends Shape {
  double radius;
  Circle(this.radius);
  @override
  double area() => 3.14159 * radius * radius;
}

class Rectangle extends Shape {
  double w, h;
  Rectangle(this.w, this.h);
  @override
  double area() => w * h;
}

void printArea(Shape s) {
  print(s.area()); // correct method called based on actual type
}

void main() {
  printArea(Circle(5));       // 78.53...
  printArea(Rectangle(4, 6)); // 24.0
}
```

## Compile-Time Polymorphism

Dart does **not** support method overloading (same name, different parameters). Use named constructors or optional parameters instead.

```dart
// Dart approach — named constructors
class Point {
  double x, y;
  Point(this.x, this.y);
  Point.zero() : x = 0, y = 0;
}
```

## `is` and `as` Operators

```dart
Shape s = Circle(3);

if (s is Circle) {
  print('It is a circle with radius ${(s as Circle).radius}');
}

// Smart cast — after `is` check, Dart auto-promotes the type
if (s is Circle) {
  print(s.radius); // no cast needed here
}
```

---
## Polymorphism with Lists

```dart
List<Shape> shapes = [
  Circle(3),
  Rectangle(4, 5),
  Circle(1),
];

for (var shape in shapes) {
  print(shape.area()); // polymorphic dispatch
}
```

---
## Key Concepts

|Concept|Description|
|---|---|
|**Upcasting**|Store child as parent type — implicit, always safe|
|**Downcasting**|Cast parent back to child — use `as`, may throw|
|**`is` check**|Safe type test before downcasting|
|**Dynamic dispatch**|Runtime selects the correct overridden method|
