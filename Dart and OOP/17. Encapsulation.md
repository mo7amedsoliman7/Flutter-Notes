## What is Encapsulation?

Encapsulation is the practice of **hiding internal state** and exposing only what is necessary through a controlled interface.

---
## Privacy in Dart

Dart uses **library-level** privacy, not class-level. A name prefixed with `_` is private to the **file** (library).

```dart
class BankAccount {
  double _balance = 0; // private field

  void deposit(double amount) {
    if (amount > 0) _balance += amount;
  }

  double get balance => _balance; // controlled read access
}
```

---
## Why Encapsulate?

- Protects internal state from invalid changes
- Allows internal implementation to change without affecting users
- Makes APIs cleaner and easier to use

---
## Public vs Private

|Syntax|Access|
|---|---|
|`name`|Public — accessible anywhere|
|`_name`|Private — accessible only within the same file|

---
## Encapsulation with Getters & Setters

Use getters for read-only access, setters for validated writes.

```dart
class Temperature {
  double _celsius;

  Temperature(this._celsius);

  double get fahrenheit => _celsius * 9 / 5 + 32;

  set celsius(double value) {
    if (value < -273.15) throw ArgumentError('Below absolute zero');
    _celsius = value;
  }
}
```

---
## Notes

- Dart does **not** have `private`, `protected`, or `public` keywords
- Privacy is enforced at the **library** (file) boundary
- Splitting a class across files removes `_` privacy between them
