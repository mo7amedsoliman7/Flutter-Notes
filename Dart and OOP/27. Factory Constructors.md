## What is a Factory Constructor?

A factory constructor uses the `factory` keyword and can **return an existing instance** or a subtype — unlike regular constructors which always create a new object.

---
## Basic Factory Constructor

```dart
class Logger {
  static final Logger _instance = Logger._internal();

  factory Logger() => _instance; // always returns the same instance

  Logger._internal(); // private constructor

  void log(String msg) => print('[LOG] $msg');
}

void main() {
  var a = Logger();
  var b = Logger();
  print(identical(a, b)); // true — same object
}
```

---
## Factory for Caching

```dart
class Color {
  final int r, g, b;
  static final Map<String, Color> _cache = {};

  Color._internal(this.r, this.g, this.b);

  factory Color(int r, int g, int b) {
    final key = '$r,$g,$b';
    return _cache.putIfAbsent(key, () => Color._internal(r, g, b));
  }
}
```

## Factory for Returning Subtypes

Factory constructors can return any subtype of the class.

```dart
abstract class Animal {
  String name;
  Animal(this.name);

  factory Animal.create(String type, String name) {
    return switch (type) {
      'dog' => Dog(name),
      'cat' => Cat(name),
      _ => throw ArgumentError('Unknown animal: $type'),
    };
  }

  void speak();
}

class Dog extends Animal {
  Dog(String name) : super(name);
  @override
  void speak() => print('$name: Woof!');
}

class Cat extends Animal {
  Cat(String name) : super(name);
  @override
  void speak() => print('$name: Meow!');
}

void main() {
  var a = Animal.create('dog', 'Rex');
  a.speak(); // Rex: Woof!
}
```

---
## Factory vs Regular Constructor

| Feature | Regular Constructor | Factory Constructor |
|---|---|---|
| Always creates new object | ✅ | ❌ (can return cached/existing instance) |
| Can return subtype | ❌ | ✅ |
| Can contain complex logic | Limited | ✅ |
| Access to `this` before initialization | ❌ | ❌ |
| Uses `new` instance internally | ✅ | Optional |
| Typical use | Normal object creation | Singleton, caching, parsing, abstraction |

## `fromJson` Pattern

Factory constructors are widely used for deserialization.

```dart
class User {
  final String name;
  final int age;

  User({required this.name, required this.age});

  factory User.fromJson(Map<String, dynamic> json) {
    return User(
      name: json['name'] as String,
      age: json['age'] as int,
    );
  }

  Map<String, dynamic> toJson() => {'name': name, 'age': age};
}

void main() {
  var json = {'name': 'Alice', 'age': 30};
  var user = User.fromJson(json);
  print(user.name); // Alice
}
```
