## What is Abstraction?

Abstraction means **hiding implementation details** and exposing only the essential interface.

---
## Abstract Classes

An abstract class cannot be instantiated directly. It defines a contract for subclasses.

```dart
abstract class Animal {
  String name;

  Animal(this.name);

  void speak(); // abstract method — no body

  void breathe() => print('$name is breathing'); // concrete method
}

class Dog extends Animal {
  Dog(String name) : super(name);

  @override
  void speak() => print('$name says: Woof!');
}
```

---
## Abstract Methods

An abstract method has **no body** — subclasses are forced to implement it.

```dart
abstract class Shape {
  double area();   // must be implemented
  double perimeter(); // must be implemented

  void describe() {
    print('Area: ${area()}, Perimeter: ${perimeter()}');
  }
}
```

---
## Can't Instantiate Abstract Classes

```dart
// Shape s = Shape(); // ❌ Error: Abstract classes can't be instantiated

Shape s = Circle(5);  // ✅ Polymorphism — store child as parent
s.describe();
```

---
## Abstract Class vs Interface

| Feature | Abstract Class | Interface (`implements`) |
|---|---|---|
| Can have concrete methods | ✅ | ✅ (must re-implement) |
| Can have fields | ✅ | ✅ (must re-implement getters/setters) |
| Constructor | ✅ (used by subclasses) | ❌ |
| Multiple use | `extends` one only | `implements` many |
| Method inheritance | Inherited directly | Must override all members |
| State sharing | ✅ Yes | ❌ No shared implementation/state |
| Typical use | Base behavior + shared logic | Contract / capability definition

## Real-World Example

```dart
abstract class DatabaseService {
  Future<List<Map>> fetchAll(String table);
  Future<void> insert(String table, Map data);
  Future<void> delete(String table, int id);
}

class FirebaseService extends DatabaseService {
  @override
  Future<List<Map>> fetchAll(String table) async { /* Firebase logic */ return []; }

  @override
  Future<void> insert(String table, Map data) async { /* ... */ }

  @override
  Future<void> delete(String table, int id) async { /* ... */ }
}
```
