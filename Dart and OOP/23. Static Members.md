## What are Static Members?

Static members belong to the **class itself**, not to any instance. They are shared across all instances.

---
## Static Fields

```dart
class Counter {
  static int count = 0;

  Counter() {
    count++;
  }
}

void main() {
  Counter();
  Counter();
  Counter();
  print(Counter.count); // 3
}
```

---
## Static Methods

Static methods cannot access instance members (`this` is not available).

```dart
class MathUtils {
  static double square(double x) => x * x;
  static double cube(double x) => x * x * x;
  static double max(double a, double b) => a > b ? a : b;
}

void main() {
  print(MathUtils.square(4)); // 16.0
  print(MathUtils.max(3, 7)); // 7.0
}
```

---
## Static vs Instance

| Feature                 | Static                                | Instance                         |
| ----------------------- | ------------------------------------- | -------------------------------- |
| Belongs to              | Class                                 | Object                           |
| Access via              | `ClassName.member`                    | `object.member`                  |
| `this` available        | ❌                                     | ✅                                |
| Shared across instances | ✅                                     | ❌ (each object has its own copy) |
| Memory allocation       | Once per class                        | Per object instance              |
| Common use cases        | Utilities, constants, shared counters | Object-specific data/behavior    |

## Constant Static Fields

Combine `static` and `const` for class-level constants.

```dart
class AppConfig {
  static const String appName = 'MyApp';
  static const int version = 1;
  static const String baseUrl = 'https://api.example.com';
}

void main() {
  print(AppConfig.appName);  // MyApp
  print(AppConfig.baseUrl);  // https://api.example.com
}
```

## Singleton Pattern with Static

```dart
class DatabaseConnection {
  static DatabaseConnection? _instance;

  DatabaseConnection._internal();

  static DatabaseConnection get instance {
    _instance ??= DatabaseConnection._internal();
    return _instance!;
  }

  void query(String sql) => print('Running: $sql');
}

void main() {
  var db1 = DatabaseConnection.instance;
  var db2 = DatabaseConnection.instance;
  print(identical(db1, db2)); // true — same instance
}
```

---
## Notes

- Static methods are resolved at compile time — no polymorphic dispatch
- Avoid overusing static: it makes testing harder (can't mock static calls easily)
- Prefer `static const` over `static final` for compile-time constants
